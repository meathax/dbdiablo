# Diablo and Hellfire data

Downloader_MiSTer installs the five required game archives listed in the repository's `external_files.csv` into this directory:

- `DIABDAT.MPQ` for the base game
- `hellfire.mpq`, `hfmonk.mpq`, `hfmusic.mpq`, and `hfvoice.mpq` for Hellfire

The core stores configuration and saved games separately in `/media/fat/saves/Diablo/`.
